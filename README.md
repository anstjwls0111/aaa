# 웨어러블 장애물 감지 장치

> 어르신 낙상(넘어짐) 사고 예방을 위한 발 부착형 야간 안전 장치  
> **플랫폼: micro:bit + MicroPython**

---

## 구성 부품

| 역할 | 부품 | 수량 |
|------|------|------|
| 메인보드 | micro:bit (v1 / v2 모두 가능) | 1 |
| 거리 감지 | HC-SR04 초음파 센서 | 1 |
| 밝기 감지 | CDS 광센서 + 10kΩ 저항 | 1세트 |
| 경고음 | 액티브 부저 모듈 | 1 |
| 경고등 / 조명 | RGB LED (공통 음극, 4핀) + 220Ω 저항 × 3 | 1세트 |
| 기타 | 점퍼선, 브레드보드 | 적당량 |

---

## 핀 배치

```
micro:bit 엣지 커넥터
├── P0  ────→  HC-SR04 TRIG
├── P1  ←────  HC-SR04 ECHO
├── P2  ←────  CDS 광센서 (10kΩ 풀다운 분압)
├── P8  ────→  액티브 부저 (+)
├── P12 ────→  RGB LED R (220Ω 직렬)
├── P13 ────→  RGB LED G (220Ω 직렬)
├── P14 ────→  RGB LED B (220Ω 직렬)
├── 3V  ────→  각 부품 VCC
└── GND ────→  각 부품 GND / RGB LED 공통 음극
```

### CDS 광센서 분압 회로
```
3V ──┬── CDS ──┬── P2 (read_analog)
     └── GND  10kΩ
              └── GND
```
어두울수록 CDS 저항↑ → P2 전압↓ → read_analog() 값 작아짐

## 작동 흐름

```
전원 ON → "READY" 스크롤 표시
  │
  ├─ 광센서 밝음 (낮)  → 절전 모드 (💤 이미지, 모두 OFF)
  │
  └─ 광센서 어두움 (밤) → 야간 감지 모드
         │
         ├─ 거리 > 50cm   : 안전  → 흰색 LED + ♥ 표시 + 무음
         ├─ 거리 20~50cm  : 경고  → 흰색 LED + ↓ 표시 + 삐… 삐…
         └─ 거리 < 20cm   : 위험  → 빨강 LED 깜빡 + ✕ 표시 + 삐삐삐삐
```

## micro:bit 디스플레이 상태

| 상태 | LED 매트릭스 |
|------|-------------|
| 절전(낮) | `Image.ASLEEP` (눈 감은 얼굴) |
| 안전(밤) | `Image.HEART` |
| 경고 | `Image.ARROW_S` (아래 화살표) |
| 위험 | `Image.NO` (X 표시, 부저와 함께 깜빡) |

## 임계값 조정

`wearable_obstacle_detector.py` 상단에서 수정:

```python
LIGHT_THRESHOLD = 400   # 높이면 더 밝아도 야간 모드 진입 (0~1023)
DIST_DANGER     = 20    # 위험 판정 거리 (cm)
DIST_WARN       = 50    # 경고 판정 거리 (cm)
```

광센서 실제 값은 **REPL 창**에서 확인:
```python
from microbit import *
print(pin2.read_analog())   # 밝을 때와 어두울 때 값 비교 후 조정
```

## 발표 포인트

- **자동차 후방감지기와 동일한 원리** → 가까울수록 삐삐 간격 짧아짐
- **낮엔 완전 절전** → 배터리 절약, 밤에만 동작
- LED 두 가지 역할: 평소(흰색 발밑 조명) / 위험(빨강 경고)
- micro:bit LED 매트릭스로 상태를 한눈에 확인 가능
- 타깃: 농촌 마을 어르신 낙상 사고 예방
