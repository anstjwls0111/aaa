# 웨어러블 장애물 감지 장치

> 어르신 낙상(넘어짐) 사고 예방을 위한 발 부착형 야간 안전 장치

---

## 구성 부품

| 역할 | 부품 | 수량 |
|------|------|------|
| 메인보드 | Arduino Uno | 1 |
| 거리 감지 | HC-SR04 초음파 센서 | 1 |
| 밝기 감지 | CDS 광센서 (아날로그) | 1 |
| 경고음 | 액티브 부저 | 1 |
| 경고등 / 조명 | RGB LED (공통 음극) | 1 |
| 기타 | 저항(10kΩ, 220Ω), 점퍼선, 브레드보드 | 적당량 |

---

## 핀 배치

```
Arduino Uno
├── D2  ────→  HC-SR04 TRIG
├── D3  ←────  HC-SR04 ECHO
├── D4  ────→  부저 (+)
├── D9  ────→  RGB LED R (220Ω 저항 직렬)
├── D10 ────→  RGB LED G (220Ω 저항 직렬)
├── D11 ────→  RGB LED B (220Ω 저항 직렬)
└── A0  ←────  CDS 광센서 (10kΩ 풀다운 분압)
```

> **RGB LED 공통 음극 연결**: 공통 핀(가장 긴 다리) → GND

---

## 작동 흐름

```
전원 ON
  │
  ├─ 광센서 밝음 (낮)  ─→  절전 모드 (LED·부저 모두 OFF)
  │
  └─ 광센서 어두움 (밤) ─→  야간 감지 모드
         │
         ├─ 거리 > 50cm   : 안전   – 흰색 LED (발밑 조명), 무음
         ├─ 거리 20~50cm  : 경고   – 흰색 LED, 부저 삐… 삐…
         └─ 거리 < 20cm   : 위험   – 빨간 LED 깜빡, 부저 삐삐삐삐
```

## 조정 방법

`wearable_obstacle_detector.ino` 상단의 임계값 수정:

```cpp
#define LIGHT_THRESHOLD   400   // 높이면 더 밝아도 야간 모드 진입
#define DIST_DANGER       20    // 위험 판정 거리 (cm)
#define DIST_WARN         50    // 경고 판정 거리 (cm)
```

광센서 실제 값은 Serial Monitor(9600 baud)로 확인 후 조정하세요.

## 발표 포인트

- **자동차 후방감지기와 동일한 원리** → 거리가 가까울수록 삐삐 간격이 짧아짐
- **낮엔 절전** → 배터리 절약, 밤에만 동작
- LED가 두 가지 역할: 평소(흰색 조명) / 위험(빨강 경고)
- 타깃: 농촌 마을 어르신 낙상 사고 예방
