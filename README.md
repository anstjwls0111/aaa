# 발에 차는 스마트 안전 감지기 (어르신 낙상 예방)

밤에 골목길을 걸을 때 신발/발목에 차고 다니며, 앞에 돌부리·턱·장애물이 있으면
**소리와 빛으로 미리 알려주는** 마이크로비트 장치입니다.

## 작동 흐름
- **낮** (광센서가 밝음) → 작동 안 함 (절전)
- **밤** (광센서가 어두움) → 켜짐 + 흰색 LED로 발밑 비춤
- 걷다가 앞에 장애물 발견 → 초음파 센서가 거리 측정
  - **멀면** → 조용
  - **가까우면** → 부저 "삐 … 삐" (느림)
  - **더 가까우면** → "삐..삐..삐" (보통)
  - **아주 가까우면** → "삐삐삐삐" (빠름) + LED 빨강 깜빡

## 구성 (4개)
| 종류 | 부품 | 역할 |
|------|------|------|
| 입력 | 초음파 센서(HC-SR04) | 앞쪽 장애물 거리 측정 (메인) |
| 입력 | 아날로그 광센서 | 어두울 때만 작동 (절전) |
| 출력 | 부저/스피커 | 가까울수록 빠른 경고음 |
| 출력 | RGB 네오픽셀 LED | 평소 흰색 조명 / 위험 시 빨강 경고 |

## 핀 연결
- 초음파 Trig → **P1**, Echo → **P2**
- 아날로그 광센서 → **P0**
- 네오픽셀 RGB LED → **P8**
- 부저음 → 마이크로비트 **내장 스피커**

## 사용 방법
1. [MakeCode 마이크로비트](https://makecode.microbit.org)에서 새 프로젝트 생성
2. 좌측 하단 톱니바퀴 → **확장(Extensions)** 에서 `sonar`, `neopixel` 추가
3. 우측 상단 `JavaScript`를 눌러 `Python`으로 바꾸고 `main.py` 내용 붙여넣기
4. 마이크로비트에 다운로드

## 조정 팁
- `DARK_LEVEL` : 낮/밤 판단 기준 (현장 밝기에 맞춰 조정, 0~1023)
- `DANGER / WARN / NOTICE` : 경고 거리 단계(cm) 조정
